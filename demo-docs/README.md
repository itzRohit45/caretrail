# Sample documents

Simulated prescriptions, lab reports, discharge summaries and a scan report, generated by `scripts/demo-docs/build.mjs`. All clinics, doctors, patients and values are fictional.

- `ravi/`: the documents uploaded to the test account.
- `overlap-test/`: two prescriptions from two doctors with the same medicines under other brands (`p1.pdf`, `p2.jpg`).
- `fresh/`: a prescription photo to try a new upload.
- `lakshmi/`, `arun/`: more patients, used by the automated tests (`arun/lab_report.pdf` is a lipid profile).
